# About this folder — historical design refs (read-only)

These markdown ledgers were imported from RequestFlo as design reference. They
are **historical and partly dated** (the `themes.md` here describes an older
"iris indigo / dark-first" system that has since been replaced by **Hot Signal**:
hot coral on deep navy, warm paper, Bricolage Grotesque headlines, pill buttons).

**They are NOT the authoritative source for swarmy's UI.** The source of truth is:

- `skill("hot-signal-design")` — swarmy's product (`apps/app`) design system.
- `skill("design-reference")` — `@swarmy/ui` package + `apps/web` marketing site.
- `skill("react-components")` — React/component/data conventions.

Use these files only as background on patterns (component decomposition, UX
flows, layout reasoning). When anything here conflicts with the skills above, the
skills win.
