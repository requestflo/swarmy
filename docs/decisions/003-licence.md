# DR-003: Licence

## Context and Problem Statement

This was already decided in the code when DR-001 started the record system. It was written down on 2026-11-27 from the product docs' "Explicitly rejected" sections and dated owner decisions, and accepted the same day.

## Considered Options

- FSL-1.1, becoming Apache 2.0 after 2 years (chosen)
- Plain Apache 2.0

## Decision Outcome

Chosen option: FSL-1.1, becoming Apache 2.0 after 2 years, because blocks resale as a competing managed service.

Turned down: Plain Apache 2.0.
