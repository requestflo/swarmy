# DR-004: Information architecture

## Context and Problem Statement

This was already decided in the code when DR-001 started the record system. It was written down on 2026-11-27 from the product docs' "Explicitly rejected" sections and dated owner decisions, and accepted the same day.

## Considered Options

- Two planes: the estate and the app workspace (chosen)
- One filterable graph; a flat 15-item sidenav

## Decision Outcome

Chosen option: Two planes: the estate and the app workspace, because operators think of infrastructure and apps as separate things.

Turned down: One filterable graph; a flat 15-item sidenav.
